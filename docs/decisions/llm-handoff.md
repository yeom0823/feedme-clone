# 결과 내보내기와 LLM 넘기기

## Decisions

- ChatGPT·Claude로 열 때 보낼 텍스트가 URL 전달 한도 이하이면 `?q=`에 실어 새 대화를 열고, 한도를 넘으면 전체 텍스트를 클립보드에 복사한 뒤 새 대화를 엽니다. 본문을 잘라 보내지 않습니다.
- 프롬프트는 복사와 LLM 열기에 "프롬프트 + 빈 줄 + Markdown"으로 포함하고, `.md` 다운로드에는 넣지 않습니다. 공백만 있는 프롬프트는 없는 것으로 봅니다.
- 프롬프트는 어디에도 저장하지 않습니다.

## Why

테스트한 기사들의 Markdown이 6,000–34,000자여서 URL에 모두 실으면 열리지 않거나 잘릴 가능성이 큽니다. 짧은 글은 URL로 바로 넘기는 편이 사용자 동작이 한 번 적습니다.

## Boundaries

- 한도 값(현재 6,000자, 인코딩 전)은 실측하지 못한 가정입니다. 실제 한도에 맞춰 바꿔도 이 결정과 어긋나지 않습니다.

## Reconsider when

- ChatGPT나 Claude가 `q` 파라미터 동작을 바꾸거나, 실측한 URL 한도가 현재 값과 크게 다를 때

## Still-rejected alternatives

- feedme.wiki처럼 9만 자 안팎도 그대로 `?q=`에 싣는 방식
- 항상 클립보드로 넘기기, 항상 URL로 넘기기, 원문 URL만 전달하기
